how this list was built

Dwell time from every visitor is pooled into a matrix of people against products, with each person's row scaled to unit length so that a single heavy browser cannot dominate. Cosine similarity between two product columns then measures whether the same people gave both their attention — regardless of how popular either one is. The number on each tile is that similarity, from 0 to 1.
